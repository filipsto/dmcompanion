# Data Modeler Companion Examples

Explore database diagrams and property graphs with Data Modeler Companion (DMC). Each example includes a self-contained `.dmcd` diagram, display previews, and a README with its source and setup details.

To explore a diagram, download its `.dmcd` file and open it in VS Code with the DMC extension installed. A database connection is not required to view the saved diagram.

## Oracle Database

- [HR property graph](Oracle%20Database/LP%20Graph/HR/README.md): Explore the HR sample schema as tables and as a property graph, including a modified graph definition with additional labels.
- [OraGram property graph](Oracle%20Database/LP%20Graph/OraGram/README.md): View the Ora-Gram-Book graph and its underlying tables, including graph relationships shown as implied foreign keys.

## SQL Server

- [AdventureWorks](SQL%20Server/AdventureWorks/README.md): Compare relational and graph displays based on AdventureWorks, with examples of generated SQL scripts and definitions.
- [FishGraph](SQL%20Server/FishGraph/README.md): Explore node and edge tables for a discussion forum in table, detailed graph, and compact graph displays.

>**Note:** Generating SQL Server create scripts or definitions for diagram objects requires a connection to the SQL Server database containing those objects.
